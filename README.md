# Revere

A quiet single page. It states what Revere builds — one shared world model per facility — and a contact address. It does not show deployments, customers, or the team.

## Local preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173.

## Deploy

Vercel serves the repository root as a static site. Push to the connected production branch to trigger deployment. No build step.
