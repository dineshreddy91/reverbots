# Revere Robotics

Static robotics landing page with the supplied animated logo and general-purpose positioning. Retail fulfillment in existing grocery stores is presented as one application, with human supervision central to that narrative.

## Local preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173. The perspective button cycles messages; the pause button stops animation and automatic rotation. Reduced-motion preferences disable animation and automatic rotation by default.

## Deploy

Vercel serves the repository root as a static site. Push to the connected production branch to trigger deployment. No build step or external dependencies.
